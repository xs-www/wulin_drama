## modify_attr     -> 修改属性  
#### 参量（param）：

构成方式：属性名 + 修改方向 + 数值 + 百分号（可选） + 比例基准（有百分号时可选，空表示b） + (基准属性)
*属性名*
    ATK = 攻击  
    HP = 当前血量  
    MHP = 生命上限  
    SPD = SPEED = 速度  
    NRG = ENERGY = 能量 
    HTE = HATEVALUE = 仇恨

*修改方向*  

    \+  增加  
    \-  减少  
    =   赋值/设置/修改为  ##危险操作

*数值*  

    不为0的正整数（暂定）

*百分号（%）*

    %   数值是否为百分比  

*比例基准（bmr）*

    b   基础数值（角色本体数值）
    m   最大数值（角色的数值上限（常见于生命、能量等有明确最大值的属性）
    r   当前属性（角色当前数值）

*基准属性*

    (attr)  基准属性名（无该项意味以被修改属性为基准）

**e.g.**

**ATK+10%b**    -> 提高等同于10%基础攻击力的攻击  
**HP+20**       -> 恢复20生命值（无法超过生命上限）   
**MHP-1%r**     -> 最大生命值减少1%（由于最大生命值在局内不随受伤改变，因此b/r/m是一个效果）  
**ENERGY+50%m** -> 恢复50%最大能量（等效于 *NRG+50%m* ）  
**SPD=10**      -> 设置速度为10  
**ATK=200%r**   -> 攻击力翻倍（等效于 *ATK+100%r* ）   
**ATK+50%r(SPD)**   -> 提高等同于50%速度值的攻击  
**HP+300%r(NRG)**   -> 恢复等同于300%当前能量的生命值  

#### 模式（mode）

| 关键字               | 含义        |      备注    |
| ----------------- | --------- | --- |
| `self`            | 自己             |
| `targer`          | 战斗目标选择器选择 |
| `source`          | 伤害来源          |
| `player`          | 玩家             |    玩家属性只有 血量、金钱 可以修改 |

##### 模式拼接
|前缀|后缀|数量|
|---|---|---|
| `all` | `enemy` | `:x` |
| `random` | `ally` |
| `other` |
| `highest{ATTR}`| 
| `lowest{ATTR}` |

**示例**  
 `all_enemy` 全体敌人.  
 `random_enemy:1` 随机1名敌方角色.  
 `all_enemy:1` 错误语法，抛出ParseError.  
 `all_ally` 全体己方角色.  
 `other_ally` 其他己方角色.  
 `random_ally:3` 随机3名己方角色.  
 `highestHTE_enemy` 仇恨最高的敌方角色.  
 `highestHP_enemy:3` 血量最高的3名敌方角色.  
 `lowest_ally` 错误语法，抛出ParseError.  
  

**全量使用**

    {
        "type": "modify_attr",
        "param": "ATK+10",
        "mode": "self"
    } // 使自身攻击力+10
    {
        "type": "modify_attr",
        "param": "HTE+20%r",
        "mode": "highestHTE_ally"
    } // 使仇恨最高的队友仇恨值提高20%

### cause_damage    -> 造成伤害

#### 参量（param）

构成方式：数值 + 百分号 + 比例基准 + 属性名

*数值*

 不为0的正整数（暂定）

 *百分号（%）*

    %   数值是否为百分比  

*比例基准（bmr）*

    b   基础数值（角色本体数值）
    m   最大数值（角色的数值上限（常见于生命、能量等有明确最大值的属性）
    r   当前属性（角色当前数值）

*属性名*  

    ATK = 攻击  
    HP = 当前血量  
    MHP = 生命上限  
    SPD = SPEED = 速度  
    NRG = ENERGY = 能量  

**e.g.**

**80%rATK**     -> 造成80%当前攻击的伤害
**20%mMHP**     -> 造成20%最大生命值的伤害  
**5**           -> 造成5点固定伤害  
**120%rATK+50%mNRG**    -> 造成120%当前攻击力+50%最大能量的伤害 ## 允许拼接倍率，但不推荐
